# 🤖 Automação de Tarefas com Python

Repositório dedicado ao armazenamento de scripts, exercícios e projetos desenvolvidos ao longo dos meus estudos de automação com Python.

## 📚 Base de estudo

Este repositório segue como base o livro **"Automatize Tarefas Maçantes com Python"**, de Al Sweigart.

## 🎯 Objetivo

Organizar e acompanhar minha evolução no aprendizado de automação de tarefas utilizando Python, aplicando conceitos práticos para otimizar atividades repetitivas do dia a dia.

## 📂 Estrutura

Os arquivos estão organizados conforme o progresso dos estudos, podendo incluir:

* Scripts de automação
* Exercícios práticos
* Anotações
* Pequenos projetos
* Testes de código

## 🚀 Tecnologias utilizadas

* Python

## 📈 Progresso

Este repositório está em constante atualização conforme avanço nos estudos e desenvolvimento de novos scripts.

## 🤝 Contribuição

Este é um projeto de estudo pessoal, mas sugestões e dicas são sempre bem-vindas!
